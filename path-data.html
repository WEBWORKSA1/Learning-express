Data, Excel & SQL Line

Turn spreadsheets into decisions with formulas, SQL and clear charts.

🚉 6 stations⏱ ~60 hours total💸 All resources free🎯 Analysts-in-training, admin and operations staff, students and small-business owners.

Every organisation runs on data, yet most of it sits in spreadsheets that nobody fully understands. People who can clean, query and explain that data become indispensable quickly — often without a computer-science degree.

This line moves from spreadsheet confidence to SQL, statistics and storytelling with charts. Each station ends with a mini-project using a real public dataset so you leave with a portfolio, not just notes.

Destination: Three portfolio analyses, working SQL skills and a dashboard you can show in interviews.

0 stations · 0%

The route

  1. 1Spreadsheet power skills~10 h

    Cell references, lookups, pivot tables, conditional formatting and data validation. Rebuild a messy budget into a clean, auditable model.

    Microsoft Excel help & learning ↗Google Sheets training ↗

  2. 2Cleaning data~8 h

    Handle duplicates, inconsistent dates, blanks and outliers. Write down every cleaning step so someone else could repeat your work exactly.

    Kaggle Learn: Data Cleaning ↗

  3. 3SQL fundamentals~12 h

    SELECT, WHERE, GROUP BY, JOIN and subqueries. Practise in the browser until joins feel natural.

    SQLBolt interactive lessons ↗Kaggle Learn: Intro to SQL ↗

  4. 4Statistics you will actually use~12 h

    Averages vs. medians, spread, sampling, correlation vs. causation and A/B tests. Learn to say how confident you are, not just what the number is.

    Khan Academy Statistics ↗OpenStax Introductory Statistics ↗

  5. 5Charts & storytelling~8 h

    Choose the right chart, remove clutter and write a headline that states the insight. Present one analysis in five slides or fewer.

    Data Visualization Catalogue ↗

  6. 6Python for analysis~10 h

    Use pandas to load, clean and summarise data in notebooks — the bridge to data-science roles.

    Kaggle Learn: Pandas ↗freeCodeCamp Data Analysis ↗

FAQ

Excel or Google Sheets?

Either. The concepts are nearly identical; employers care that you can model and explain data.

Is SQL hard?

Basic SQL is one of the fastest technical skills to learn — most people write useful queries within a week.
