Coding & Web Dev Line

From your first HTML tag to a deployed portfolio project.

🚉 6 stations⏱ ~120 hours total💸 All resources free🎯 Absolute beginners and self-taught coders who keep restarting tutorials.

Web development remains one of the most accessible paths into tech because everything you need is free: a browser, a text editor and the open web. What most beginners lack is not material but order. This line gives you the order.

Follow the stations in sequence and build something at every stop. By the end you will have a responsive portfolio site, a JavaScript app that talks to a real API and a public code history that shows employers how you think.

Destination: A deployed portfolio, two JavaScript projects and a GitHub profile with regular commits.

0 stations · 0%

The route

  1. 1HTML: structure~10 h

    Learn semantic tags, headings, links, images, forms and accessibility basics. Build a single-page profile with valid, well-structured markup.

    MDN Learn web development ↗freeCodeCamp curriculum ↗

  2. 2CSS: layout & responsive design~15 h

    Master the box model, Flexbox, Grid and media queries. Rebuild your profile so it looks great from a phone to a wide monitor.

    web.dev Learn CSS ↗W3Schools CSS ↗

  3. 3JavaScript fundamentals~30 h

    Variables, functions, arrays, objects, loops and the DOM. Make your page interactive with a theme switcher, a form validator and a to-do list.

    javascript.info ↗freeCodeCamp JavaScript ↗

  4. 4Git & GitHub~6 h

    Version control is non-negotiable on a team. Learn commits, branches and pull requests, then publish your site for free with GitHub Pages.

    GitHub Skills ↗Pro Git book ↗

  5. 5APIs & async JavaScript~20 h

    Fetch real data, handle loading and errors, and build a weather or book-search app. This is where tutorials end and engineering begins.

    MDN: Using Fetch ↗Public APIs list ↗

  6. 6Full curriculum & computer science~39 h

    Go deeper with a complete open curriculum and a university-grade intro to computer science. Pick one and finish it.

    The Odin Project ↗Harvard CS50x ↗
